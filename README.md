# Музей Боевой Славы имени И. А. Будая

Сайт музея ГУО «Боровлянская гимназия» (аг. Лесной, ул. Мирная 10Б).

## Страницы

- `index.html` — главная: история основания, основатель, разделы экспозиции, направления работы, блок «Беларусь помнит».
- `budai.html` — биография, деятельность и награды И. А. Будая.
- `aleksandrov.html` — биография, научная работа и сохранение памяти Н. Н. Александрова.

## Структура

```
index.html
budai.html
aleksandrov.html
css/style.css
js/script.js
fonts/            Lora (OFL) + Truetypewriter PolyglOTT
assets/img/       фотографии, бумага, баннер, логотипы, иконки
```

Сборка не нужна — это статический сайт. Достаточно открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

и открыть `http://127.0.0.1:8000/`.

## Карта

В подвале встроена интерактивная карта Яндекс.Карт с адресом гимназии:
`Республика Беларусь, 223040, Минская область, Минский район, аг. Лесной, ул. Мирная 10Б`.
Координаты: `54.008259, 27.683663`.

## Особенности вёрстки

- макет рассчитан на ширину 1440 px, контент — 1376 px;
- баннер и подвал с эффектом оторванной бумаги;
- крупный текст (34 px), заголовки 72 px, курсив;
- бумажные карточки: Lora Medium, красный текст; даты — Lora SemiBold;
- адаптив для планшетов и телефонов (1024 / 768 / 420 px);
- изображения с `loading="lazy"` и собственными размерами.
